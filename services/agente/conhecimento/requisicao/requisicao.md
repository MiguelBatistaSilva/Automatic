# Requisição de Serviço

- Matrícula do usuário afetado, edifício, fila e técnico atribuído são o
  que o técnico costuma informar. Se faltar algum, pergunte — menos a fila:
  sem ela, o sistema usa a do técnico (ou devolve a pergunta).
- Tombo: são os 6 últimos dígitos do código da máquina
  (FCBVCUSTO265287 → 265287). O sistema faz esse corte sozinho.
- Uma requisição por tombo. O tombo vai na descrição e no Item B (com `*`).
- Resumo: "Requisição de Serviço". Categoria: quase sempre "Instalar /
  Configurar".
- Item e Categoria seguem a CONVENÇÃO da equipe, não o nome (troca de
  ventoinha é Computador / Instalar / Configurar). Use os exemplos da
  ferramenta; se nenhum bater com o pedido, pergunte ao técnico.
